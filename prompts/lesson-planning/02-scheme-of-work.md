# Scheme of Work Generator

## Purpose
Create a medium-term plan covering a unit or topic over multiple lessons.

## Prompt

```
Create a scheme of work for teaching [TOPIC] in [SUBJECT] to [YEAR_GROUP] students over [NUMBER] lessons/weeks.

Context:
- Examination Board: [EXAM_BOARD]
- Specification Reference: [SPEC_REFERENCE]
- Ability Level: [ABILITY_LEVEL]
- Target Grade: [TARGET_GRADE]

For each lesson, please provide:
1. Lesson title and focus
2. Key learning objectives (linked to specification)
3. Key content to cover
4. Suggested activities
5. Assessment opportunities
6. Resources needed
7. Homework tasks
8. Cross-curricular links where appropriate

Also include:
- Prior knowledge required
- Common misconceptions across the topic
- Key vocabulary list
- End of unit assessment suggestions
- Opportunities for SMSC (Spiritual, Moral, Social, Cultural) development
```

## Differentiated Version

```
Create a fully differentiated scheme of work for [TOPIC] in [SUBJECT] to [YEAR_GROUP].

For each lesson, provide three pathways:
- Foundation pathway (working towards Grade [X])
- Core pathway (targeting Grade [Y])
- Higher pathway (aiming for Grade [Z])

Include scaffolding suggestions for students with:
- [NEURODIVERGENCE]
- English as an Additional Language
- Specific learning difficulties
```
