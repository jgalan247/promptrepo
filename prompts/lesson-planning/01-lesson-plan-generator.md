# Lesson Plan Generator

## Purpose
Generate a comprehensive lesson plan tailored to specific requirements.

## Prompt

```
Create a detailed lesson plan for teaching [TOPIC] in [SUBJECT] to [YEAR_GROUP] students.

Context:
- Examination Board: [EXAM_BOARD]
- Ability Level: [ABILITY_LEVEL]
- Target Grade: [TARGET_GRADE]
- Lesson Duration: [TIME_AVAILABLE]
- Class Size: [CLASS_SIZE]
- Available Resources: [RESOURCES_AVAILABLE]

Learning Objectives:
[LEARNING_OBJECTIVES]

Please include:
1. Starter activity (5-10 minutes) - to engage students and assess prior knowledge
2. Main teaching content with clear explanations
3. Student activities with differentiation for different ability levels
4. Assessment for learning opportunities throughout
5. Plenary/consolidation activity
6. Homework suggestions
7. Resources needed
8. Key vocabulary
9. Common misconceptions to address
10. Extension activities for early finishers

Format the plan with clear timings and transitions between activities.
```

## Neurodivergent Adaptation

```
Create a detailed lesson plan for teaching [TOPIC] in [SUBJECT] to [YEAR_GROUP] students.

Context:
- Examination Board: [EXAM_BOARD]
- Ability Level: [ABILITY_LEVEL]
- Target Grade: [TARGET_GRADE]
- Lesson Duration: [TIME_AVAILABLE]
- Neurodivergent Considerations: [NEURODIVERGENCE]

Please include all standard lesson plan elements PLUS:
- Visual schedule/timeline for the lesson
- Built-in movement breaks or brain breaks
- Sensory considerations and accommodations
- Clear transition warnings and cues
- Scaffolded instructions broken into small steps
- Alternative ways to demonstrate understanding
- Quiet space/time-out options if needed
- Reduced cognitive load strategies
```

## Example Usage

**Input:**
- Topic: Quadratic Equations

- Year Group: Year 10
- Exam Board: Edexcel

- Time: 1 hour
