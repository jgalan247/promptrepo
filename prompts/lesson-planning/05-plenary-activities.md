# Plenary Activities Generator

## Purpose
Create effective lesson endings that consolidate learning and assess understanding.

## Prompt

```
Generate 5 different plenary activities for a [SUBJECT] lesson on [TOPIC] for [YEAR_GROUP] students.

Context:
- Learning Objectives Covered: [LEARNING_OBJECTIVES]
- Ability Level: [ABILITY_LEVEL]
- Time Available: 5-10 minutes

For each plenary, provide:
1. Activity name and format
2. Step-by-step instructions
3. How it assesses the learning objectives
4. What to do with common incorrect responses
5. How it prepares for next lesson

Include variety:
- One self-assessment activity
- One peer-assessment activity
- One retrieval/recall activity
- One application/transfer activity
- One metacognitive reflection activity
```

## Quick Exit Ticket Ideas

```
Generate 10 quick exit ticket questions for [TOPIC] in [SUBJECT] that:
- Take 2-3 minutes to complete
- Cover the key learning points
- Identify misconceptions
- Are suitable for [ABILITY_LEVEL]
- Can be easily sorted into "Got it / Nearly there / Need help" piles
```
