# Learning Objectives Generator

## Purpose
Generate clear, measurable learning objectives aligned to specifications and ability levels.

## Prompt

```
Generate differentiated learning objectives for a [SUBJECT] lesson on [TOPIC] for [YEAR_GROUP] students.

Context:
- Examination Board: [EXAM_BOARD]
- Ability Range: [ABILITY_LEVEL]
- Target Grades: [TARGET_GRADE]

Please provide:

1. THREE tiered objectives using "All/Most/Some" format:
   - All students will... (minimum expectation)
   - Most students will... (expected progress)
   - Some students will... (extended challenge)

2. The same objectives rewritten using Bloom's Taxonomy verbs at different levels

3. Student-friendly "I can..." statements for each tier

4. Success criteria for each objective (what does achieving this look like?)

5. How these link to the exam specification command words

Ensure objectives are:
- Specific and measurable
- Achievable within the lesson timeframe
- Progressive in difficulty
- Linked to assessable outcomes
```

## SEND-Adapted Version

```
Generate learning objectives for [TOPIC] that are accessible for students with [NEURODIVERGENCE].

Provide:
- Simplified "I can..." statements using clear, concrete language
- Visual success criteria (what it looks like when done)
- Chunked micro-objectives for complex tasks
- Alternative ways to demonstrate achievement
- Self-assessment checkpoints
```
