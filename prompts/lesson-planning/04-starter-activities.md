# Starter Activities Generator

## Purpose
Generate engaging starter activities to begin lessons effectively.

## Prompt

```
Generate 5 different starter activities for a [SUBJECT] lesson on [TOPIC] for [YEAR_GROUP] students.

Context:
- Ability Level: [ABILITY_LEVEL]
- Time Available: 5-10 minutes
- Previous Topic Covered: [PREVIOUS_TOPIC]

For each starter, provide:
1. Activity name and type (e.g., retrieval practice, hook, diagnostic)
2. Clear instructions
3. Resources needed
4. How it links to the main lesson
5. Differentiation suggestions
6. How to assess student responses

Include a variety of types:
- One retrieval practice activity (reviewing prior learning)
- One diagnostic activity (assessing starting points)
- One hook/engagement activity (generating curiosity)
- One literacy-based activity (key vocabulary focus)
- One collaborative activity (pair/group work)
```

## Low-Preparation Version

```
Generate 5 "no-prep" starter activities for [SUBJECT] lessons that:
- Require no printing or resources
- Can be done with mini-whiteboards or notebooks
- Work for any topic in [SUBJECT]
- Take exactly 5 minutes
- Are suitable for [ABILITY_LEVEL] students
```

## Neurodivergent-Friendly Starters

```
Generate starter activities for students with [NEURODIVERGENCE] that:
- Have clear, simple instructions (maximum 3 steps)
- Include movement or hands-on elements
- Provide immediate feedback
- Allow for different response methods
- Have predictable structures students can learn
- Include calming/focusing options for regulation
```
