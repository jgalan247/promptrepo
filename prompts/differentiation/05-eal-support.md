# EAL (English as Additional Language) Support Generator

## Purpose
Create materials and strategies for students learning English as an additional language.

## Prompt

```
Adapt the following for students with English as an Additional Language:

Original material/activity: [DESCRIBE_MATERIAL]
Subject: [SUBJECT]
Year Group: [YEAR_GROUP]
Student's English Proficiency Level: [EAL_LEVEL: New to English / Early Acquisition / Developing / Competent]
Student's First Language: [FIRST_LANGUAGE]

Provide:

1. VOCABULARY SUPPORT
   - Key vocabulary with simple definitions
   - Visual representations of key terms
   - First language translations where helpful
   - Word banks for the activity
   - Tier 2 (academic) vocabulary explained

2. LANGUAGE SCAFFOLDS
   - Sentence stems and frames
   - Model responses
   - Key phrases for the subject
   - Speaking and writing supports

3. VISUAL SUPPORTS
   - Diagrams and images to support understanding
   - Graphic organisers
   - Labelled examples
   - Dual-language resources if available

4. ADAPTED INSTRUCTIONS
   - Simplified instructions
   - Step-by-step with visuals
   - Check for understanding points
   - Demonstration suggestions

5. DIFFERENTIATED OUTCOMES
   - How student can demonstrate understanding
   - Alternative response methods
   - Partial participation options
   - Extension if appropriate

6. PEER SUPPORT STRATEGIES
   - Buddy system suggestions
   - Group role assignments
   - Collaborative learning structures
```

## Subject-Specific EAL Vocabulary

```
Create an EAL-friendly vocabulary resource for [TOPIC] in [SUBJECT]:

For each key term provide:
- The word
- Simple definition (avoid other complex words)
- Visual representation description
- Example sentence using the word
- Common collocations
- Word family (noun, verb, adjective forms)
```
