# Neurodivergent Adaptations Generator

## Purpose
Adapt materials and activities for neurodivergent learners.

## ADHD Adaptations Prompt

```
Adapt the following [ACTIVITY_TYPE] for students with ADHD:

Original activity: [DESCRIBE_ACTIVITY]
Subject: [SUBJECT]
Year Group: [YEAR_GROUP]
Duration: [TIME_AVAILABLE]

Please provide adaptations including:

1. ATTENTION MANAGEMENT
   - How to chunk the activity into smaller segments
   - Movement break opportunities
   - Attention reset strategies
   - Novelty elements to maintain engagement

2. ORGANISATION SUPPORT
   - Visual task lists
   - Time management tools
   - Material organisation strategies
   - Clear workspace setup

3. IMPULSIVITY MANAGEMENT
   - Wait time strategies
   - Response structures
   - Self-monitoring tools
   - Redirection techniques

4. MOTIVATION STRATEGIES
   - Immediate feedback opportunities
   - Choice within the activity
   - Interest-based modifications
   - Progress visualisation
```

## Autism/ASD Adaptations Prompt

```
Adapt the following activity for autistic students:

Original activity: [DESCRIBE_ACTIVITY]
Subject: [SUBJECT]
Year Group: [YEAR_GROUP]

Please provide adaptations including:

1. COMMUNICATION CLARITY
   - Explicit, literal instructions
   - Remove ambiguity and idioms
   - Visual supports for verbal instructions
   - Written backup for spoken information

2. SENSORY CONSIDERATIONS
   - Environmental modifications
   - Sensory break options
   - Alternative materials if needed
   - Quiet space provisions

3. ROUTINE AND PREDICTABILITY
   - Clear structure and sequence
   - Transition warnings
   - Change management strategies
   - Visual schedules

4. SOCIAL INTERACTION SUPPORT
   - Structured group work options
   - Individual alternatives where appropriate
   - Clear role definitions
   - Scripts for collaborative tasks

5. SPECIAL INTERESTS
   - How to incorporate interests where possible
   - Choice within activities
   - Motivation through interests
```

## Universal Design Prompt

```
Apply Universal Design for Learning principles to [ACTIVITY_TYPE]:

Provide adaptations across all three UDL principles:

1. MULTIPLE MEANS OF ENGAGEMENT (the "why")
   - Choice and autonomy options
   - Relevance and authenticity
   - Self-regulation supports

2. MULTIPLE MEANS OF REPRESENTATION (the "what")
   - Alternative formats for information
   - Clarification of vocabulary
   - Multiple media options

3. MULTIPLE MEANS OF ACTION & EXPRESSION (the "how")
   - Alternative response methods
   - Scaffolded practice
   - Executive function supports
```
