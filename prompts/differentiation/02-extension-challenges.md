# Extension and Challenge Generator

## Purpose
Create enrichment activities for higher-attaining students or early finishers.

## Prompt

```
Create extension activities for [TOPIC] in [SUBJECT] for [YEAR_GROUP] students.

Context:
- Core Learning Objectives: [LEARNING_OBJECTIVES]
- Target Grade for Extension: [TARGET_GRADE]
- Examination Board: [EXAM_BOARD]

Provide:

1. DEPTH EXTENSIONS (going deeper)
   - Questions requiring deeper analysis
   - "Why does this work?" investigations
   - Counter-examples to explore
   - Edge cases to consider

2. BREADTH EXTENSIONS (going wider)
   - Cross-curricular connections
   - Real-world applications
   - Historical context
   - Current affairs links

3. COMPLEXITY EXTENSIONS (increasing challenge)
   - Multi-step problems
   - Questions with less scaffolding
   - Open-ended investigations
   - Exam questions from harder papers/boards

4. METACOGNITIVE EXTENSIONS
   - Teaching others (create explanations)
   - Finding alternative methods
   - Evaluating different approaches
   - Creating their own questions

5. INDEPENDENT RESEARCH PROJECTS
   - Enquiry questions to investigate
   - Resources to explore
   - Presentation formats
   - Success criteria
```

## Gifted and Talented Version

```
Create extension activities specifically for Gifted and Talented students:
- Olympiad-style problems
- University-level taster content
- Independent research projects
- Competition entry preparation
- Mentoring younger students activities
```
