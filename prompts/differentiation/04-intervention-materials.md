# Intervention Materials Generator

## Purpose
Create targeted intervention materials for students who need additional support.

## Prompt

```
Create intervention materials for students struggling with [TOPIC] in [SUBJECT].

Context:
- Year Group: [YEAR_GROUP]
- Current Level: [CURRENT_LEVEL]
- Target Level: [TARGET_GRADE]
- Specific Gaps Identified: [GAPS]
- Time Available for Intervention: [TIME_AVAILABLE]

Provide:

1. DIAGNOSTIC QUESTIONS
   - 5 questions to pinpoint exact gaps
   - Analysis key for each wrong answer

2. PREREQUISITE REVIEW
   - Key prior knowledge needed
   - Mini-lesson to address gaps
   - Practice activities for prerequisites

3. RETEACHING MATERIALS
   - Alternative explanations (different from original teaching)
   - Concrete-Pictorial-Abstract progression
   - Worked examples with think-alouds
   - Common misconceptions addressed explicitly

4. GUIDED PRACTICE
   - Highly scaffolded practice questions
   - Immediate feedback opportunities
   - Success criteria checklist

5. INDEPENDENT PRACTICE
   - Gradually releasing scaffolding
   - Self-check answers
   - Progress tracking sheet

6. MASTERY CHECK
   - Assessment to confirm gap is closed
   - Next steps if not yet mastered
```

## Small Group Intervention Plan

```
Create a 6-week small group intervention plan for [TOPIC]:

Week-by-week breakdown including:
- Focus for each session
- Materials needed
- Success criteria
- Progress monitoring points
- Exit criteria (when is intervention complete?)
```
