# Scaffolding Strategies Generator

## Purpose
Create scaffolding tools and strategies to support learners at different levels.

## Prompt

```
Create scaffolding strategies for teaching [TOPIC] in [SUBJECT] to [YEAR_GROUP] students.

Context:
- Ability Level: [ABILITY_LEVEL]
- Learning Objectives: [LEARNING_OBJECTIVES]
- Specific Challenge: [CHALLENGE_AREA]

Provide scaffolding for:

1. WRITING SCAFFOLDS
   - Sentence starters for different question types
   - Paragraph structures (e.g., PEEL, PEAL)
   - Connective word banks
   - Model answer annotations

2. THINKING SCAFFOLDS
   - Worked examples with commentary
   - Partially completed examples
   - Problem-solving frameworks
   - Decision trees for processes

3. VOCABULARY SCAFFOLDS
   - Word banks with definitions
   - Key term glossaries
   - Subject-specific phrase banks
   - Tier 2 and Tier 3 vocabulary lists

4. VISUAL SCAFFOLDS
   - Graphic organisers
   - Flowcharts and diagrams
   - Annotated models
   - Step-by-step visual guides

5. GRADUAL RELEASE PLAN
   - I do (teacher models)
   - We do (guided practice)
   - You do together (collaborative)
   - You do alone (independent)
```

## Removing Scaffolds (Fading)

```
Create a scaffold fading plan for [TOPIC]:
- Full scaffold version
- Partial scaffold version (50% removed)
- Minimal scaffold version (hints only)
- Independent version (no scaffold)
- How to determine when students are ready to progress
```
