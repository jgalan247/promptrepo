# Parent Communication Generator

## Purpose
Create professional communication templates for parents/carers.

## Positive Communication Prompt

```
Write a positive communication to parents about [STUDENT_ACHIEVEMENT] in [SUBJECT].

Context:
- Year Group: [YEAR_GROUP]
- Achievement: [DESCRIBE_ACHIEVEMENT]
- Communication Method: [EMAIL/LETTER/POSTCARD]

Include:
1. Warm greeting
2. Specific description of the achievement
3. Why this is significant
4. How parents can support continued success
5. Encouraging close

Tone: Warm, professional, celebratory
Length: [WORD_COUNT] words
```

## Concern Communication Prompt

```
Write a communication to parents expressing concern about [ISSUE].

Context:
- Subject: [SUBJECT]
- Year Group: [YEAR_GROUP]
- Issue: [DESCRIBE_ISSUE]
- Actions already taken: [ACTIONS]

The communication should:
1. Open in a balanced way (not immediately negative)
2. Clearly explain the concern with specific examples
3. Avoid blame or accusatory language
4. Outline school support being provided
5. Suggest partnership approaches
6. Request meeting/call if appropriate
7. End with hope and collaboration

Tone: Professional, supportive, solution-focused
```

## Progress Update Prompt

```
Write a progress update for parents on [STUDENT_NAME]'s work in [SUBJECT].

Include:
- Current working level/grade
- Target level/grade
- Strengths demonstrated
- Areas for development
- Recommended home support
- Upcoming assessments/deadlines
- How to contact with questions

Tone: Informative, balanced, supportive
```

## Sensitive Communication

```
Write a sensitive communication regarding [SENSITIVE_ISSUE]:

Issues might include:
- Learning difficulties identified
- Behavioural concerns
- Attendance issues
- Mental health observations
- Safeguarding-adjacent concerns

Include:
- Sensitive opening
- Factual, non-judgemental description
- Support being offered
- Signposting to resources
- Confidentiality assurances
- Next steps
```
