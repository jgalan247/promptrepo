# Student Communication Generator

## Purpose
Create effective written communications for students.

## Assignment Instructions Prompt

```
Write clear instructions for [ASSIGNMENT_TYPE] on [TOPIC] for [YEAR_GROUP] students.

Context:
- Subject: [SUBJECT]
- Ability Level: [ABILITY_LEVEL]
- Deadline: [DEADLINE]
- Submission Method: [METHOD]

Include:
1. WHAT to do (clear task description)
2. WHY it matters (purpose and learning)
3. HOW to complete it (step-by-step)
4. WHEN it's due (clear deadline)
5. WHERE to submit (method)
6. SUCCESS CRITERIA (what good looks like)
7. SUPPORT available (where to get help)

Format with clear headings, numbered steps, and bullet points.
```

## Neurodivergent-Accessible Instructions

```
Write instructions accessible for students with [NEURODIVERGENCE]:

- Use short sentences (max 15 words)
- One instruction per line
- Number all steps
- Use "You will..." active voice
- Include visual cues/icons descriptions
- Provide checklist format
- State explicit expectations
- Remove ambiguity
```

## Motivational Message

```
Write a motivational message for [YEAR_GROUP] students who are:
- Preparing for [EXAM_TYPE]
- Struggling with motivation
- Returning from a break
- Facing challenges

Include:
- Acknowledgement of difficulty
- Realistic encouragement
- Specific strategies
- Reminder of support available
- Growth mindset messaging
```

## Revision Guidance

```
Write revision guidance for [SUBJECT] [EXAM_BOARD] exam:

Include:
- When to start revising
- How to structure revision
- Effective techniques to use
- What to focus on
- Resources available
- Self-care reminders
- Exam day tips
```
