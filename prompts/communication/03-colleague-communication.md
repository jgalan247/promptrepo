# Colleague Communication Generator

## Purpose
Create professional communications for colleagues and leadership.

## Handover Information Prompt

```
Create a class handover document for [CLASS] in [SUBJECT].

Include:

1. CLASS OVERVIEW
   - General ability profile
   - Behaviour considerations
   - Seating plan rationale

2. INDIVIDUAL STUDENTS
   For key students include:
   - Name and key information
   - SEND requirements
   - Current levels and targets
   - What works well
   - What to avoid

3. CURRICULUM POSITION
   - Topics covered
   - Current progress
   - What's next
   - Resources location

4. ROUTINES AND SYSTEMS
   - Established routines
   - Reward/sanction approaches used
   - Homework expectations

5. ADDITIONAL NOTES
   - Parent relationships
   - Any ongoing issues
   - Recommendations for successor
```

## SENCO Referral

```
Write a referral to the SENCO regarding concerns about [STUDENT].

Include:
- Specific concerns observed
- Evidence collected (dates, examples)
- Strategies already tried
- Impact on learning
- What support is being requested
- Urgency level
```

## Cover Work Instructions

```
Write cover work instructions for [LESSON] on [TOPIC]:

Include:
- Brief context for cover teacher
- Equipment needed
- Seating plan information
- Student leaders to ask for help
- Step-by-step lesson structure
- Resources attached/location
- What to do if students finish early
- Any students to be aware of
- How to report any issues
```

## Meeting Agenda/Notes

```
Create agenda for [MEETING_TYPE]:
- Department meeting
- Parent consultation
- SEND review
- Behaviour support meeting

Include:
- Purpose and objectives
- Items to discuss with time allocations
- Decisions needed
- Action items template
- Date for follow-up
```
