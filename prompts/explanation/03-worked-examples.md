# Worked Examples Generator

## Purpose
Create detailed worked examples with clear step-by-step explanations.

## Prompt

```
Create a worked example for [PROBLEM_TYPE] in [SUBJECT] for [YEAR_GROUP].

Context:
- Topic: [TOPIC]
- Ability Level: [ABILITY_LEVEL]
- Examination Board: [EXAM_BOARD]

Provide:

1. THE PROBLEM
   - Exam-style question
   - Clear context
   - All necessary information

2. THINKING PROCESS (What I notice)
   - What type of question this is
   - What it's asking for
   - Key information to identify
   - Similar problems to connect to

3. STEP-BY-STEP SOLUTION
   For each step:
   - What to do
   - Why we do it
   - How to do it
   - Common errors to avoid

4. FINAL ANSWER
   - Clear presentation
   - Correct units/format
   - How to check the answer

5. VARIATION
   - A similar problem for students to try
   - With hints available
   - Full solution provided separately

6. EXTENSION
   - How this might be made harder
   - What to watch for in exam questions
```

## Faded Worked Examples

```
Create a faded worked example set for [PROBLEM_TYPE]:

EXAMPLE 1: Full worked example (all steps shown)
EXAMPLE 2: First 2 steps shown, students complete the rest
EXAMPLE 3: Only first step shown
EXAMPLE 4: Problem only, students complete independently

Include answers for self-checking.
```

## Self-Explanation Prompts

```
Create a worked example with self-explanation prompts:

After each step, include a question:
- "Why did I do this step?"
- "What would happen if I skipped this?"
- "What might go wrong here?"
- "Can you explain this step in your own words?"
```
