# Text Simplification Generator

## Purpose
Simplify complex texts and materials for different ability levels.

## Prompt

```
Simplify the following text for [YEAR_GROUP] students at [ABILITY_LEVEL] level.

Original text:
[PASTE_ORIGINAL_TEXT]

Subject: [SUBJECT]
Target Grade: [TARGET_GRADE]

Please provide:

1. SIMPLIFIED VERSION
   - Maintain key information
   - Use simpler vocabulary
   - Shorter sentences
   - Active voice
   - Year-appropriate reading level

2. KEY VOCABULARY GLOSSARY
   - Essential terms that must be kept
   - Simple definitions for each
   - Example sentences

3. VISUAL SUMMARY
   - Description of a visual that would support the text
   - Bullet point summary
   - Key takeaways

4. COMPREHENSION QUESTIONS
   - 3-5 questions to check understanding
   - Range from literal to inferential
```

## Reading Age Adaptation

```
Adapt this text to a reading age of [X] years:

Original text: [PASTE_TEXT]

Requirements:
- Readability score target: [FLESCH-KINCAID SCORE]
- Maximum sentence length: [X] words
- Maximum syllables per word: [X]
- Replace technical terms with: [SIMPLER ALTERNATIVES/GLOSSARY]
```

## Dyslexia-Friendly Version

```
Reformat and simplify for students with dyslexia:

- Use short paragraphs (3-4 sentences max)
- Use bullet points where possible
- Bold key terms
- Suggest dyslexia-friendly fonts
- Add subheadings for navigation
- Remove unnecessary complexity
- Maintain exam-relevant content
```
