# Concept Explainer Generator

## Purpose
Create clear explanations of concepts at different levels.

## Prompt

```
Explain [CONCEPT] in [SUBJECT] for [YEAR_GROUP] students.

Context:
- Examination Board: [EXAM_BOARD]
- Ability Level: [ABILITY_LEVEL]
- Target Grade: [TARGET_GRADE]
- Prior Knowledge: [PRIOR_KNOWLEDGE]

Please provide:

1. SIMPLE EXPLANATION
   - In student-friendly language
   - Using everyday analogies
   - Maximum 3 sentences

2. DETAILED EXPLANATION
   - Full technical explanation
   - Using correct subject terminology
   - Step-by-step breakdown

3. VISUAL EXPLANATION
   - Description of diagram/visual that would help
   - Annotated elements
   - How visual supports understanding

4. REAL-WORLD CONNECTION
   - Why this matters
   - Where students encounter this in life
   - Career relevance if applicable

5. COMMON MISCONCEPTIONS
   - What students often get wrong
   - Why these misconceptions occur
   - How to address them

6. EXAM FOCUS
   - How this appears in exams
   - Key vocabulary to use
   - Mark scheme requirements
```

## Multiple Approaches Version

```
Explain [CONCEPT] using three different approaches:

APPROACH 1: Concrete/Physical
- Hands-on demonstration
- Physical analogy
- Manipulatives to use

APPROACH 2: Visual/Pictorial
- Diagrams and images
- Graphic representations
- Colour-coding

APPROACH 3: Abstract/Symbolic
- Mathematical/formulaic
- Technical definitions
- Formal notation
```

## Neurodivergent-Friendly Explanation

```
Explain [CONCEPT] for a student with [NEURODIVERGENCE]:
- Use concrete, literal language
- Avoid idioms and metaphors (or explain them)
- Chunk into small, numbered steps
- Include visual supports
- Provide examples alongside definitions
- Highlight the "why" and relevance
```
