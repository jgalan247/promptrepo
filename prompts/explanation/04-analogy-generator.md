# Analogy and Metaphor Generator

## Purpose
Create memorable analogies and metaphors to explain complex concepts.

## Prompt

```
Create analogies to explain [CONCEPT] in [SUBJECT] for [YEAR_GROUP] students.

Context:
- Abstract concept to explain: [CONCEPT]
- What makes it difficult: [DIFFICULTY]
- Students' likely prior experiences: [CONTEXT]

Please provide:

1. PRIMARY ANALOGY
   - The analogy itself
   - How each part maps to the concept
   - Where the analogy breaks down (limitations)
   - How to explain the mapping to students

2. ALTERNATIVE ANALOGY
   - Different approach for different learners
   - May suit different interests/contexts

3. VISUAL METAPHOR
   - Description of an image that captures the concept
   - How to use it in teaching
   - What it helps students understand

4. EVERYDAY EXAMPLE
   - Where students encounter this in daily life
   - Concrete, tangible example
   - Discussion questions

5. STORY/NARRATIVE
   - Brief story that embodies the concept
   - Memorable characters or situations
   - Key learning point embedded
```

## Subject-Specific Analogy Banks

```
Create an analogy bank for [TOPIC] in [SUBJECT]:

For each key concept, provide:
- 2-3 alternative analogies
- Visual representation suggestion
- When to use each analogy
- Cautions/limitations
```

## Neurodivergent Considerations

```
Create concrete, literal explanations for autistic students:

Note: Some autistic students may find metaphors and analogies confusing.
Provide:
- Literal, direct explanations alongside analogies
- Explicit explanation of how the analogy works
- Clear statement of where the analogy is NOT literal
- Option to skip analogy and use direct explanation
```
