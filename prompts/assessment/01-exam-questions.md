# Exam-Style Questions Generator

## Purpose
Generate exam-style questions with mark schemes aligned to specification requirements.

## Prompt

```
Create exam-style questions for [TOPIC] in [SUBJECT] for [YEAR_GROUP] students.

Context:
- Examination Board: [EXAM_BOARD]
- Paper/Component: [PAPER_NUMBER]
- Target Grade: [TARGET_GRADE]

Generate the following question types:

1. SHORT ANSWER QUESTIONS (3-5 marks each)
   - 5 questions testing recall and basic application
   - Clear command words from specification
   - Mark scheme with acceptable answers

2. MEDIUM RESPONSE QUESTIONS (6-9 marks each)
   - 3 questions requiring explanation or analysis
   - Structured with part a, b, c if appropriate
   - Detailed mark scheme with levels

3. EXTENDED RESPONSE QUESTION (12+ marks)
   - 1 question requiring evaluation or extended writing
   - Clear assessment criteria
   - Level-based mark scheme
   - Example response at each level

For each question include:
- The question text
- Mark allocation
- Command word used
- Specification link
- Mark scheme/indicative content
- Common student errors
- Examiner tips
```

## Past Paper Style Analysis

```
Based on [EXAM_BOARD] [SUBJECT] past papers, create questions that:
- Mirror the exact format and style
- Use similar stem structures
- Apply the same mark allocation patterns
- Include the specific command words used
- Reflect the assessment objective weightings
```
