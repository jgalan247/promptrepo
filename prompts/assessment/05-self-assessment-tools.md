# Self-Assessment Tools Generator

## Purpose
Create tools for students to assess their own learning and progress.

## Prompt

```
Create self-assessment tools for [TOPIC] in [SUBJECT] for [YEAR_GROUP] students.

Context:
- Learning Objectives: [LEARNING_OBJECTIVES]
- Ability Level: [ABILITY_LEVEL]
- Target Grade: [TARGET_GRADE]

Include the following tools:

1. CONFIDENCE CHECKER
   - List of "I can..." statements
   - Traffic light or emoji rating scale
   - Space for evidence of each skill

2. LEARNING LADDER
   - Progression steps from basic to advanced
   - Clear descriptors at each level
   - "I am here" marker
   - "My next step is..." prompt

3. REFLECTION QUESTIONS
   - What I learned today...
   - What I found challenging...
   - What I need to practice more...
   - Questions I still have...

4. GOAL SETTING TEMPLATE
   - Current level/grade
   - Target level/grade
   - Specific actions to improve
   - Timeline for improvement

5. EXAM READINESS CHECKLIST
   - Topic coverage tracker
   - RAG rating for each sub-topic
   - Action plan for "red" areas
```

## Neurodivergent-Friendly Version

```
Create self-assessment tools for students with [NEURODIVERGENCE]:
- Visual scales (thumbs up/down, 1-5 stars)
- Simple yes/no checkboxes
- Picture-based reflection options
- Reduced writing requirements
- Clear, concrete descriptors
- Celebration of small wins built in
```
