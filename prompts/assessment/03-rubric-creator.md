# Assessment Rubric Creator

## Purpose
Create detailed rubrics for consistent assessment of student work.

## Prompt

```
Create an assessment rubric for [ASSESSMENT_TYPE] on [TOPIC] in [SUBJECT] for [YEAR_GROUP].

Context:
- Ability Level: [ABILITY_LEVEL]
- Target Grade: [TARGET_GRADE]
- Total Marks/Points: [TOTAL_MARKS]

Create a rubric with:

1. ASSESSMENT CRITERIA (4-6 criteria)
   For each criterion provide descriptors at 4 levels:
   - Excellent (full marks)
   - Good (most marks)
   - Developing (some marks)
   - Beginning (few marks)

2. CRITERIA TO INCLUDE:
   - Content knowledge and accuracy
   - Use of subject-specific terminology
   - Analysis/evaluation depth
   - Structure and organisation
   - Communication/presentation
   - [Subject-specific criteria]

3. WEIGHTING
   - How many marks each criterion is worth
   - Justification for weighting

4. HOLISTIC DESCRIPTOR
   - Overall grade descriptors
   - What distinguishes each grade band

Format as a clear grid/table structure.
```

## Single-Point Rubric Version

```
Create a single-point rubric showing:
- Central column: What proficiency looks like
- Left column: Concerns/areas for growth
- Right column: Advanced/exceeds expectations
- Space for specific feedback on each criterion
```
