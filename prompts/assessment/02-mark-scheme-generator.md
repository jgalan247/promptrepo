# Mark Scheme Generator

## Purpose
Create detailed mark schemes for assessments with clear criteria.

## Prompt

```
Create a mark scheme for assessing student work on [TOPIC] in [SUBJECT] for [YEAR_GROUP].

Context:
- Examination Board: [EXAM_BOARD]
- Assessment Type: [ASSESSMENT_TYPE]
- Total Marks: [TOTAL_MARKS]
- Target Grade Range: [TARGET_GRADE]

The mark scheme should include:

1. POINT-BASED MARKING (for factual questions)
   - Specific acceptable answers
   - Alternative acceptable responses
   - Reject criteria (what NOT to accept)
   - Maximum marks per point

2. LEVELS-BASED MARKING (for extended responses)
   - Level descriptors (typically 3-4 levels)
   - Indicative content for each level
   - How to award marks within levels
   - Quality of written communication criteria

3. ASSESSMENT OBJECTIVES MAPPING
   - Which AOs each question assesses
   - Weighting across the assessment

4. GRADE BOUNDARIES
   - Suggested thresholds for each grade
   - Based on [EXAM_BOARD] historical patterns

5. MODERATION GUIDANCE
   - How to ensure consistency
   - Borderline examples
   - Common marking errors to avoid
```

## Peer Assessment Version

```
Create a student-friendly mark scheme for peer assessment that:
- Uses accessible language
- Includes "What a good one looks like" examples
- Has clear checkboxes or criteria
- Guides students on giving constructive feedback
- Is appropriate for [ABILITY_LEVEL] students
```
