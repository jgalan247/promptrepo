# Diagnostic Assessment Generator

## Purpose
Create assessments to identify student starting points and misconceptions.

## Prompt

```
Create a diagnostic assessment for [TOPIC] in [SUBJECT] for [YEAR_GROUP] students.

Context:
- Prior Learning Expected: [PREVIOUS_TOPIC]
- Ability Level: [ABILITY_LEVEL]

The diagnostic should:

1. ASSESS PRIOR KNOWLEDGE
   - 5 questions on prerequisite knowledge
   - Identify gaps from previous learning

2. IDENTIFY MISCONCEPTIONS
   - Include questions that reveal common misconceptions
   - Use carefully designed distractors in MCQs
   - Include "explain your reasoning" questions

3. ESTABLISH STARTING POINTS
   - Questions at varying difficulty levels
   - Help place students on a learning continuum

4. QUESTION TYPES
   - 5 multiple choice (with diagnostic distractors)
   - 3 short answer
   - 2 "show your working" questions
   - 1 open-ended explanation

5. ANALYSIS GUIDANCE
   - What each wrong answer indicates
   - How to group students based on results
   - Suggested interventions for each gap identified

Time to complete: 15-20 minutes
```

## Quick Diagnostic Version

```
Create a 5-minute diagnostic "hinge question" set for [TOPIC]:
- 5 multiple choice questions
- Each wrong answer reveals a specific misconception
- Analysis key showing what each response pattern means
- Instant grouping strategy based on results
```
