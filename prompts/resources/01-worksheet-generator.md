# Worksheet Generator

## Purpose
Create differentiated worksheets with varied question types and scaffolding.

## Prompt

```
Create a worksheet for [TOPIC] in [SUBJECT] for [YEAR_GROUP] students.

Context:
- Examination Board: [EXAM_BOARD]
- Ability Level: [ABILITY_LEVEL]
- Target Grade: [TARGET_GRADE]
- Time to Complete: [TIME_AVAILABLE]

Please include:

1. TITLE SECTION
   - Clear title and date
   - Learning objective in student-friendly language
   - Space for student name

2. SCAFFOLDED QUESTIONS (15-20 questions)
   - Start with basic recall questions
   - Progress to application questions
   - Include analysis/evaluation questions
   - End with extension challenges

3. SUPPORT FEATURES
   - Worked example at the start
   - Key vocabulary box with definitions
   - Formula/key information reminder box
   - Hints for challenging questions

4. MARK SCHEME
   - Expected answers for each question
   - Common misconceptions to look for
   - Marking guidance and grade boundaries

Format the worksheet clearly with:
- Numbered questions
- Adequate space for answers
- Clear section headings
- Visual organisation
```

## Differentiated Three-Way Version

```
Create a three-way differentiated worksheet set for [TOPIC]:

BRONZE WORKSHEET (Foundation - Grade [X]):
- 10-12 questions
- More scaffolding and worked examples
- Sentence starters provided
- Simpler language
- Visual supports

SILVER WORKSHEET (Core - Grade [Y]):
- 12-15 questions
- Moderate scaffolding
- Some open-ended questions
- Standard exam-style language

GOLD WORKSHEET (Higher - Grade [Z]):
- 15-20 questions
- Minimal scaffolding
- Open-ended and synoptic questions
- Exam command words throughout
- Extension challenges
```

## Neurodivergent-Accessible Worksheet

```
Create an accessible worksheet for students with [NEURODIVERGENCE]:

Include:
- Dyslexia-friendly formatting (sans-serif font, 1.5 line spacing)
- Chunked sections with clear breaks
- Visual instructions alongside text
- Reduced questions per page
- Tick boxes for completed sections
- Colour-coded difficulty levels
- Space for rough work
- "Done" checkpoint after each section
- Options for verbal/visual responses
```
