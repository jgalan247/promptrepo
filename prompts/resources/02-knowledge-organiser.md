# Knowledge Organiser Generator

## Purpose
Create comprehensive knowledge organisers that summarise key information for a topic.

## Prompt

```
Create a knowledge organiser for [TOPIC] in [SUBJECT] for [YEAR_GROUP] students.

Context:
- Examination Board: [EXAM_BOARD]
- Target Grade: [TARGET_GRADE]

The knowledge organiser should fit on ONE A4 page and include:

1. KEY VOCABULARY (8-12 words)
   - Term and definition
   - Organised alphabetically or thematically

2. KEY FACTS/CONCEPTS (10-15 points)
   - Essential knowledge students must know
   - Bullet-pointed and concise

3. KEY DIAGRAMS/VISUALLY REPRESENTED INFORMATION
   - Description of diagrams to include
   - Timelines, flowcharts, or concept maps where appropriate

4. KEY FIGURES/DATES/FORMULAS
   - Depending on subject: important people, dates, equations, quotes

5. COMMON MISTAKES TO AVOID
   - 3-5 typical misconceptions

6. EXAM TIPS
   - Command words relevant to this topic
   - What examiners are looking for

7. LINKS TO OTHER TOPICS
   - How this connects to prior and future learning

Format for visual impact with clear sections and hierarchical organisation.
```

## Revision-Focused Version

```
Create a revision knowledge organiser for [TOPIC] that includes:

- "Must know" tier (Grade 4-5 content)
- "Should know" tier (Grade 6-7 content)
- "Could know" tier (Grade 8-9 content)
- QR code descriptions linking to video explanations
- Self-quiz questions with fold-over answers
- Spaced retrieval practice schedule
```
