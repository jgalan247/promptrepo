# Presentation Content Generator

## Purpose
Generate content and structure for teaching presentations.

## Prompt

```
Create the content for a teaching presentation on [TOPIC] in [SUBJECT] for [YEAR_GROUP].

Context:
- Examination Board: [EXAM_BOARD]
- Ability Level: [ABILITY_LEVEL]
- Lesson Duration: [TIME_AVAILABLE]
- Learning Objectives: [LEARNING_OBJECTIVES]

For each slide, provide:
1. Slide title
2. Main content (bullet points or key information)
3. Speaker notes (what to say/explain)
4. Suggested visual/image description
5. Student activity or questioning opportunity

Structure should include:
- Title slide with learning objectives
- Do Now/Starter activity slide
- New content slides (chunked appropriately)
- Worked example slides
- Student practice slides
- Check for understanding slides
- Plenary slide
- Homework/next steps slide

Design principles to follow:
- Maximum 6 bullet points per slide
- One key idea per slide
- Clear, readable fonts suggested
- Consistent colour scheme notes
- Animation suggestions for revealing information
```

## Dual-Coding Version

```
Create a presentation following dual-coding principles:
- Every concept has both visual and verbal representation
- Suggest specific diagrams, icons, or images for each point
- Include retrieval practice opportunities
- Use visual organisers (timelines, flowcharts, Venn diagrams)
- Minimise text, maximise meaningful visuals
```

## Accessible Presentation

```
Create presentation content accessible for students with [NEURODIVERGENCE]:
- High contrast colour suggestions
- Simple, consistent layouts
- Clear signposting of lesson stages
- Built-in processing time prompts
- Reduced visual clutter
- Predictable structure throughout
```
