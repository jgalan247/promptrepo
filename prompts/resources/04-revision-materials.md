# Revision Materials Generator

## Purpose
Create various revision resources for exam preparation.

## Prompt

```
Create a comprehensive revision pack for [TOPIC] in [SUBJECT] for [YEAR_GROUP] students.

Context:
- Examination Board: [EXAM_BOARD]
- Target Grade: [TARGET_GRADE]
- Time Until Exam: [TIME_AVAILABLE]

Include the following revision materials:

1. REVISION CHECKLIST
   - All sub-topics to cover
   - Self-assessment RAG rating column
   - Resource links for each area

2. FLASHCARD SET (20 cards)
   - Question on front
   - Answer on back
   - Mix of recall, application, and explanation

3. MIND MAP TEMPLATE
   - Central concept
   - Main branches
   - Key details on each branch
   - Links between concepts

4. PRACTICE QUESTIONS
   - 5 short-answer questions
   - 3 medium-response questions
   - 1 extended response question
   - Model answers for each

5. COMMON ERRORS GUIDE
   - Typical mistakes students make
   - How to avoid them
   - Examiner tips

6. QUICK-FIRE QUIZ (20 questions)
   - Mix of question types
   - Answers provided
```

## Spaced Practice Schedule

```
Create a 4-week spaced revision schedule for [TOPIC] that:
- Incorporates retrieval practice
- Increases intervals between reviews
- Mixes topics for interleaving
- Includes self-testing checkpoints
- Builds to exam-style questions
```
