# Graphic Organiser Generator

## Purpose
Create visual thinking tools and graphic organisers for learning.

## Prompt

```
Create a set of graphic organisers for teaching [TOPIC] in [SUBJECT] to [YEAR_GROUP].

For each organiser, provide:
- Type and purpose
- Structure/layout description
- Example content filled in
- Blank template instructions
- How students should use it

Include these organiser types:

1. CONCEPT MAP
   - Central concept with branching ideas
   - Shows relationships between concepts
   - Hierarchical structure

2. COMPARE AND CONTRAST
   - Venn diagram or T-chart format
   - Clear categories for similarities/differences

3. CAUSE AND EFFECT
   - Fishbone diagram or flowchart
   - Shows chains of causation

4. SEQUENCE/PROCESS
   - Step-by-step flowchart
   - Timeline format if chronological

5. MAIN IDEA AND DETAILS
   - Central idea with supporting evidence
   - Useful for essay planning

6. VOCABULARY ORGANISER
   - Word, definition, example, non-example
   - Visual representation space
```

## SEND-Friendly Organisers

```
Create simplified graphic organisers for students with [NEURODIVERGENCE]:
- Clear boxes with defined spaces
- Numbered sequence for completion
- Visual cues and icons
- Reduced writing requirements
- Colour-coded sections
- Example showing completed version
```
