# Discussion Questions Generator

## Purpose
Create questions that promote deep discussion and critical thinking.

## Prompt

```
Create discussion questions for [TOPIC] in [SUBJECT] for [YEAR_GROUP].

Context:
- Key Theme/Concept: [THEME]
- Prior Knowledge: [PRIOR_KNOWLEDGE]
- Ability Level: [ABILITY_LEVEL]

Please provide:

1. OPENING DISCUSSION QUESTIONS
   - 3 questions to start conversation
   - Accessible to all
   - Connect to prior knowledge or experience

2. DEEPENING QUESTIONS
   - 5 questions that push thinking deeper
   - Require evidence or justification
   - Have multiple valid perspectives

3. CONTROVERSIAL/DEBATE QUESTIONS
   - 3 questions with no clear "right" answer
   - Encourage respectful disagreement
   - Develop critical thinking

4. CONNECTING QUESTIONS
   - 3 questions linking to other topics/subjects
   - Real-world connections
   - Personal relevance

5. METACOGNITIVE QUESTIONS
   - 3 questions about the thinking process
   - "What made you think that?"
   - "Has your thinking changed?"

For each question include:
- Discussion format suggestion (pairs/groups/whole class)
- Time allocation
- Possible student responses to anticipate
- How to manage if discussion stalls
```

## Structured Academic Controversy

```
Create a Structured Academic Controversy activity for [TOPIC]:

The Question: [DEBATABLE_QUESTION]

POSITION A materials:
- Key arguments
- Evidence to use
- Counter-arguments to expect

POSITION B materials:
- Key arguments
- Evidence to use
- Counter-arguments to expect

Discussion protocol and synthesis questions.
```
