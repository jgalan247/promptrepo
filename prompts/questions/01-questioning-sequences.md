# Questioning Sequences Generator

## Purpose
Create effective questioning sequences for classroom dialogue.

## Prompt

```
Create a questioning sequence for teaching [TOPIC] in [SUBJECT] to [YEAR_GROUP].

Context:
- Learning Objective: [LEARNING_OBJECTIVES]
- Ability Level: [ABILITY_LEVEL]
- Lesson Stage: [STARTER/MAIN/PLENARY]

Please provide:

1. RECALL QUESTIONS (Lower Order)
   - 5 questions checking basic knowledge
   - Closed questions with clear answers
   - Building block facts needed

2. COMPREHENSION QUESTIONS
   - 5 questions checking understanding
   - "Explain...", "Describe...", "What does X mean?"
   - In own words

3. APPLICATION QUESTIONS
   - 5 questions requiring use of knowledge
   - New contexts or scenarios
   - "How would you...?", "Apply this to..."

4. ANALYSIS QUESTIONS
   - 5 questions requiring breaking down
   - "Why does...?", "What is the relationship...?"
   - Compare and contrast

5. EVALUATION QUESTIONS (Higher Order)
   - 5 questions requiring judgement
   - "To what extent...?", "How effective...?"
   - Justifying opinions

6. SYNTHESIS/CREATION QUESTIONS
   - 3 questions requiring creating new ideas
   - Open-ended, no single right answer
   - Design, propose, hypothesise

For each question, include:
- The question
- Expected student response level
- Follow-up prompts if students struggle
- Extension prompts if students answer fully
```

## Socratic Questioning Sequence

```
Create a Socratic questioning sequence to help students discover [CONCEPT]:

1. Opening question (probing assumptions)
2. Clarifying questions
3. Questions that probe reasons and evidence
4. Questions about viewpoints and perspectives
5. Questions about implications and consequences
6. Questions about the question itself

Include expected student responses and teacher responses to guide thinking.
```

## Cold Call Question Bank

```
Create a bank of questions for cold calling during [TOPIC]:

- Quick recall questions (30-second think time)
- Medium questions (1-minute think time)
- Deep questions (2-minute think time with partner discussion)

Include correct answers and common misconceptions for each.
```
