# Hinge Questions Generator

## Purpose
Create diagnostic hinge questions to check understanding at key points.

## Prompt

```
Create hinge questions for [TOPIC] in [SUBJECT] for [YEAR_GROUP].

Context:
- Key Concept: [CONCEPT]
- Common Misconceptions: [MISCONCEPTIONS]
- Learning Objective: [LEARNING_OBJECTIVES]

For each hinge question provide:

1. THE QUESTION
   - Multiple choice format (4-5 options)
   - Only ONE correct answer
   - Each wrong answer reveals a specific misconception

2. ANSWER ANALYSIS
   - Correct answer and why
   - For each distractor:
     - What misconception it reveals
     - What the student might be thinking
     - How to address this in teaching

3. RESPONSE STRATEGY
   - If most choose A: [action]
   - If most choose B: [action]
   - If most choose C: [action]
   - If split: [action]

4. FOLLOW-UP MINI-LESSON
   - Brief reteaching script for each misconception
   - Quick activity to correct understanding

Create 5 hinge questions covering the key concepts in [TOPIC].
```

## Quick Diagnostic Set

```
Create a 5-minute diagnostic check for [TOPIC]:

5 multiple choice questions where:
- Each tests a different concept
- Wrong answers are diagnostic (reveal specific gaps)
- Can be answered on mini-whiteboards
- Provides instant feedback opportunity

Include a decision tree: "If students get X wrong, teach Y"
```
