# Retrieval Practice Questions Generator

## Purpose
Create spaced retrieval practice activities to strengthen memory.

## Prompt

```
Create retrieval practice questions for [TOPIC] in [SUBJECT] for [YEAR_GROUP].

Context:
- When topic was taught: [TIMING]
- Key knowledge to retrieve: [KEY_KNOWLEDGE]
- Target Grade: [TARGET_GRADE]
- Previous topics to interleave: [PREVIOUS_TOPICS]

Please provide:

1. QUICK-FIRE RECALL (10 questions)
   - Single fact/definition questions
   - Answer in one word or short phrase
   - Cover essential knowledge

2. SHORT ANSWER RETRIEVAL (5 questions)
   - Require 1-2 sentence answers
   - Test connections between ideas
   - Include "How?" and "Why?" questions

3. APPLICATION RETRIEVAL (3 questions)
   - Apply remembered knowledge to new situation
   - Require deeper processing
   - Show understanding, not just recall

4. INTERLEAVED QUESTIONS (5 questions)
   - Mix questions from [TOPIC] with [PREVIOUS_TOPICS]
   - Help students distinguish between concepts
   - Strengthen related knowledge

5. ELABORATIVE RETRIEVAL (2 questions)
   - Ask students to explain connections
   - Generate examples from memory
   - Make links to other subjects/life

Include:
- Answers for self-checking
- Feedback for common errors
- Spacing schedule (when to revisit)
```

## Weekly Retrieval Quiz Template

```
Create a weekly retrieval quiz format for [SUBJECT]:

Structure:
- 2 questions from this week
- 3 questions from last week
- 3 questions from last month
- 2 questions from last term

Include template for generating these each week.
```

## Brain Dump Activities

```
Create brain dump retrieval activities for [TOPIC]:

1. Free recall: Write everything you remember about [TOPIC]
2. Structured recall: Fill in this concept map from memory
3. Paired recall: Take turns recalling facts with partner
4. Competitive recall: Team challenge format

Include success criteria and checking mechanisms.
```
