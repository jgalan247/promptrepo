# Peer Feedback Guides Generator

## Purpose
Create structures and guides for effective student peer assessment.

## Prompt

```
Create a peer feedback guide for [ASSESSMENT_TYPE] in [SUBJECT] for [YEAR_GROUP].

Context:
- Topic: [TOPIC]
- Ability Level: [ABILITY_LEVEL]
- Success Criteria: [SUCCESS_CRITERIA]

Provide:

1. FEEDBACK RULES POSTER
   - 5-6 key rules for giving peer feedback
   - Appropriate language to use
   - Respectful behaviour expectations

2. FEEDBACK SENTENCE STARTERS
   For strengths:
   - "Something you did really well was..."
   - "I liked how you..."
   - "This was effective because..."

   For improvements:
   - "To improve, you could try..."
   - "Next time, consider..."
   - "One thing to develop is..."

3. FEEDBACK CHECKLIST
   - Criteria-based checklist students can tick
   - Traffic light assessment options
   - Space for comments

4. QUALITY CONTROL
   - Example of good feedback vs poor feedback
   - What makes feedback helpful
   - Practice activity

5. RESPONSE TO FEEDBACK
   - How to receive feedback
   - How to act on feedback
   - Reflection prompts
```

## Structured Peer Assessment Protocol

```
Create a structured protocol for peer assessment:

STEP 1: Read/Review (5 mins)
- Instructions for silent review
- What to look for

STEP 2: Identify Strengths (3 mins)
- Template for positive comments
- Minimum 2 strengths

STEP 3: Suggest Improvements (3 mins)
- Template for constructive suggestions
- Maximum 2 targets

STEP 4: Discuss (5 mins)
- Questions to ask each other
- Clarification opportunities

STEP 5: Respond (5 mins)
- Template for action planning
- Commitment to improvements
```
