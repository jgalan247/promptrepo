# Report Comment Generator

## Purpose
Generate professional report comments for different contexts.

## End of Term Report Prompt

```
Generate a report comment for [STUDENT_DESCRIPTION] in [SUBJECT] for [YEAR_GROUP].

Context:
- Current Grade/Level: [CURRENT_GRADE]
- Target Grade/Level: [TARGET_GRADE]
- Attitude to Learning Grade: [ATL_GRADE]
- Homework Completion: [HOMEWORK_STATUS]
- Ability Level: [ABILITY_LEVEL]
- Report Type: [INTERIM/END OF TERM/END OF YEAR]

Key achievements this term: [ACHIEVEMENTS]
Areas to develop: [AREAS_TO_DEVELOP]

The report should:
1. Open with a positive statement about the student
2. Comment on specific achievements with examples
3. Reference the curriculum content covered
4. Identify 1-2 specific targets for improvement
5. Include advice on how to improve
6. Close with an encouraging statement

Word limit: [WORD_LIMIT] words

Tone should be:
- Professional and formal
- Positive but honest
- Specific rather than generic
- Parent-friendly (avoid jargon)
```

## Personalised Comment Bank

```
Create a bank of report comments for [SUBJECT] at [YEAR_GROUP] level:

Provide 5 comments for each category:

ATTITUDE TO LEARNING:
- Excellent ATL
- Good ATL
- Satisfactory ATL
- Needs improvement ATL

PROGRESS:
- Exceeding expectations
- Meeting expectations
- Working towards expectations
- Below expectations

TARGETS:
- For students aiming at higher grades
- For students at target grade
- For students below target grade

CLOSING STATEMENTS:
- For strong students
- For improving students
- For struggling students
```

## SEND-Specific Reports

```
Generate a sensitive report comment for a student with [NEURODIVERGENCE]:

- Acknowledge reasonable adjustments made
- Celebrate progress relative to starting point
- Focus on individual achievements
- Set realistic, achievable targets
- Use strength-based language
- Avoid deficit-focused phrasing
```
