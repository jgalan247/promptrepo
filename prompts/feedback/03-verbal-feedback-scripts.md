# Verbal Feedback Scripts Generator

## Purpose
Create scripts for effective verbal feedback conversations with students.

## Prompt

```
Create a verbal feedback script for discussing [STUDENT_ISSUE] with a [YEAR_GROUP] student.

Context:
- Subject: [SUBJECT]
- Student Ability: [ABILITY_LEVEL]
- Target Grade: [TARGET_GRADE]
- Specific Issue: [ISSUE_DESCRIPTION]
- Student Personality: [STUDENT_DESCRIPTION]

Provide a script that includes:

1. OPENING
   - How to start the conversation positively
   - Putting the student at ease
   - Setting the purpose of the conversation

2. POSITIVE RECOGNITION
   - Specific strengths to acknowledge
   - Recent improvements to celebrate
   - Effort recognition

3. AREA FOR DEVELOPMENT
   - How to introduce the issue sensitively
   - Questions to help student self-identify
   - Avoid accusatory language

4. COLLABORATIVE PROBLEM-SOLVING
   - Questions to ask the student
   - How to involve them in solutions
   - Options to offer

5. ACTION PLANNING
   - Agreeing specific next steps
   - How to phrase targets
   - Support available

6. CLOSING
   - Summarising agreements
   - Expressing confidence
   - Arranging follow-up

Include:
- Alternative phrasings for different responses
- What to do if student becomes defensive/upset
- Follow-up suggestions
```

## Difficult Conversation Scripts

```
Create a script for addressing [DIFFICULT_SITUATION]:
- Persistent homework non-completion
- Declining effort/engagement
- Behaviour impacting learning
- Underperformance despite ability
- Peer conflict affecting work

Include de-escalation strategies and restorative approaches.
```
