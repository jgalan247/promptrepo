# Written Feedback Generator

## Purpose
Generate constructive, actionable feedback on student work.

## Prompt

```
Generate feedback for a [YEAR_GROUP] student's [ASSESSMENT_TYPE] on [TOPIC] in [SUBJECT].

Context:
- Target Grade: [TARGET_GRADE]
- Current Grade Achieved: [CURRENT_GRADE]
- Ability Level: [ABILITY_LEVEL]
- Examination Board: [EXAM_BOARD]

Student's work summary: [DESCRIBE_WORK]

Main strengths observed: [STRENGTHS]

Areas for improvement: [IMPROVEMENTS]

Please provide feedback that:

1. OPENS POSITIVELY
   - Specific praise for what was done well
   - Reference to actual elements of the work
   - Acknowledge effort and progress

2. IDENTIFIES 2-3 TARGETS
   - Specific and actionable improvement points
   - Linked to mark scheme/success criteria
   - Prioritised by impact on grade

3. PROVIDES NEXT STEPS
   - Clear actions the student can take
   - Examples of what improved work would look like
   - Resources or strategies to support improvement

4. CLOSES ENCOURAGINGLY
   - Motivational but realistic
   - Express confidence in ability to improve

Tone should be:
- Warm but professional
- Growth mindset oriented
- Appropriate for [ABILITY_LEVEL]
```

## Quick Feedback Codes

```
Create a set of feedback codes for [SUBJECT] marking:

For each code provide:
- Code number/letter
- What it means
- The improvement action required
- Example correction

Categories:
- Content/Knowledge codes
- Skill codes
- Technical accuracy codes
- Presentation codes
- Exam technique codes
```

## Neurodivergent-Friendly Feedback

```
Write feedback for a student with [NEURODIVERGENCE]:

- Use clear, direct language
- Be specific and concrete (avoid vague praise/criticism)
- Limit to 2 improvement targets maximum
- Include visual elements if possible (stars, checkmarks)
- Provide a clear single next step
- Celebrate specific achievements
- Avoid overwhelming with too much text
```
